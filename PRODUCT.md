# Product
Open-source web framework for community-branded Hub child sites. Hosts use separate parent and child themes while private providers enforce identity, community scope and competition permissions.

## Platform
Web, responsive desktop and mobile.

## Admin
Extend the existing theme tokens and native controls with a conventional administration sidebar. First release supports presentation drafts, preview and validated configuration download. It does not persist changes or grant administrative access to private Hub data. The deployment pipeline remains responsible for publication.
